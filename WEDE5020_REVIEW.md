# WEDE5020 Website Review and Improvement Summary

## Pages reviewed
1. index.html - Home page, clear hero, mission content, calls to action, responsive layout.
2. about.html - Mission, vision, values and organisation/team content.
3. services.html - Service information presented with icons and responsive layout.
4. projects.html - Project information plus project image showcase.
5. get-involved.html - Volunteer opportunities, support information and validated volunteer form.
6. gallery.html - Accessible image gallery, lazy-loaded images and JavaScript lightbox with keyboard controls.
7. contact.html - Contact information and validated contact form.

## Technical improvements
- Shared CSS moved to `css/style.css`.
- Shared JavaScript moved to `js/script.js`.
- All local images are stored in `images/`.
- All local links and image paths were checked. No broken local paths were found.
- Navigation is consistent across all pages.
- Active navigation state is added with JavaScript and `aria-current`.
- Responsive navigation and content grids were added.
- Forms use labels, required fields and client-side validation.
- Gallery supports lightbox, previous/next controls, Escape, and arrow keys.
- Images use descriptive alt text and lazy loading where appropriate.
- Back-to-top control was added.
- Removed the malformed duplicate CSS file.
- Removed inline styling from the pages so presentation is controlled by the shared stylesheet.
- Added the new image collection to the gallery and selected project showcase.

## Assessment focus
The site demonstrates:
- Multi-page HTML5 structure.
- Semantic sections, headings, lists, figures and forms.
- Consistent navigation and internal linking.
- CSS-based visual design.
- JavaScript interactivity.
- Responsive design.
- Accessibility considerations.
- Appropriate use of images and alternative text.
- Clear content related to the Hope Connect Foundation project.
