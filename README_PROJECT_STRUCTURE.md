# Hope Connect Foundation - Final Organised Structure

## Main folders

- `css/` - shared website styling
- `js/` - shared JavaScript functionality
- `images/` - website images

## HTML pages

- `index.html`
- `about.html`
- `services.html`
- `projects.html`
- `get-involved.html`
- `gallery.html`
- `contact.html`

## Shared files

Every page uses:

```html
<link rel="stylesheet" href="css/style.css">
<script src="js/script.js"></script>
```

Images use paths such as:

```html
<img src="images/logo.png" alt="Hope Connect Foundation Logo">
```
